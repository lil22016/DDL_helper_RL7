Deadline Garden — Push Notification Setup (custom reminder version)

The website now stores reminder rules in the synced garden_state JSON. No new column is required.

Default reminder schedule:
- Daily summary at 8:00 AM local time.
- 5 hours, 2 hours, 1 hour, and 15 minutes before each unfinished due date.

Users can change this under Account → Reminder schedule. They may add any number of reminders, mix specific local times with “before deadline” offsets, and delete reminders down to one remaining rule.

BACKEND UPDATE REQUIRED ONCE:
1. In Supabase SQL Editor, run:
   supabase/migrations/20261010_custom_reminders.sql

2. Replace/redeploy the Edge Function with:
   supabase/functions/send-deadline-notifications/index.ts

3. Keep the existing Edge Function secrets:
   VAPID_PUBLIC_KEY
   VAPID_PRIVATE_KEY
   VAPID_SUBJECT
   SUPABASE_URL
   SUPABASE_SERVICE_ROLE_KEY

4. Keep send-deadline-notifications scheduled every 5 minutes.

The frontend still uses the existing push_subscriptions table and timezone recorded by the browser. The urgent in-page warning/red-screen logic is unchanged.
